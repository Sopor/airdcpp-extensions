# How to configure airdcpp-tiny-fileserver

### <ins>Folder to serve .tgz files from</ins>
* Enter the path to the folder you have created for installation and/or updating of extensions.

### <ins>Port to listen on (1024-65535)</ins>
* Leave empty for port 8912 or change it if you want.

### <ins>Also listen to these addresses (optional, comma-separated)</ins>
* If you have "Network interface for all connections" set to something else that can't be auto-detected.

### <ins>Automatically install new or updated extensions when found</ins>
* When enabled, extensions copied to the specified folder are installed or updated automatically.

### <ins>Check for new/changed .tgz files every (seconds)</ins>
* This is how often it will check for any new .tgz files in the folder you have specified.
